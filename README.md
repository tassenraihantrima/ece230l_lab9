## Lab Questions

###  Why can we not just use structural Verilog to implement latches?
Verilog cannot effectively map latches.

### What is the meaning of always @(*) in a sensitivity block?
It's automatic and tells the simulator to trigger the block whenever any variable read inside it changes. 

### What importance is memory to digital circuits?
It allows circuits to have a state, allowing them to remember past events.
